Interprétation. L’ACF du log-prix décroît très lentement et sa PACF présente un seul pic proche de 1 au retard 1 : c’est le comportement d’une marche aléatoire, la série doit être différenciée. Après différenciation, l’ACF et la PACF des rendements sont presque entièrement dans la bande de confiance : les ordres \(p\) et \(q\) seront faibles. L’ACF des rendements au carré, elle, reste significative sur de nombreux retards : l’ampleur des variations est prévisible même si leur signe ne l’est pas, ce qui annonce un effet ARCH.

Stationnarité : ADF et KPSS

L’ADF a pour hypothèse nulle la non-stationnarité, le KPSS la stationnarité. Une série est déclarée non stationnaire quand l’ADF ne rejette pas et que le KPSS rejette. Les p-values de tseries sont bornées (entre 0,01 et 0,10).

# Applique les deux tests aux niveaux puis aux différences
tester <- function(x, nom, niveau) {
  x <- as.numeric(x)
  a <- adf.test(x); k <- kpss.test(x, null = if (niveau) "Trend" else "Level")
  concl <- if (a$p.value >= ALPHA && k$p.value < ALPHA) "non stationnaire" else if (a$p.value < ALPHA && k$p.value >= ALPHA) "stationnaire" else "tests en désaccord"
  data.frame(serie = nom, ADF_stat = a$statistic, ADF_p = a$p.value, KPSS_stat = k$statistic, KPSS_p = k$p.value, conclusion = concl, row.names = NULL)
}
tab_stat <- rbind(tester(train$log_BTC, "log-prix BTC", TRUE), tester(train$r_BTC, "rendement BTC", FALSE),
                  tester(train$log_ETH, "log-prix ETH", TRUE), tester(train$r_ETH, "rendement ETH", FALSE))
tableau(tab_stat, "02_tests_stationnarite")

Comme en Python : paramètres estimés sur l’apprentissage puis figés, prévision glissante à chaque jour du test, évaluation aux horizons 1, 5 et 10 jours sur les mêmes dates. La référence est la prévision naïve (« le prix ne change pas »).

# Définit les origines et l'évaluation une seule fois 
origines <- (n_train - H + 1):(N - 1)       
chemins <- list()
extraire <- function(ch, h) {
  cibles <- origines + h
  ok <- cibles > n_train & cibles <= N & !is.na(ch[, h])
  list(prev = exp(ch[ok, h]), reel = prix[cibles[ok]])
}
metriques <- function(prev, reel) { e <- reel - prev
  c(MSE = mean(e^2), RMSE = sqrt(mean(e^2)), MAE = mean(abs(e)), MAPE_pct = 100 * mean(abs(e / reel))) }

# Regroupe les trois tests dans une fonction 
diagnostic <- function(e, nom, ddl = 0) {
  e <- as.numeric(na.omit(e))
  data.frame(serie = nom,
             LjungBox10_p = Box.test(e, lag = 10, type = "Ljung-Box", fitdf = ddl)$p.value,
             LjungBox20_p = Box.test(e, lag = 20, type = "Ljung-Box", fitdf = ddl)$p.value,
             JarqueBera_p = jarque.bera.test(e)$p.value,
             kurtosis = mean((e - mean(e))^4) / mean((e - mean(e))^2)^2,
             ARCH_LM10_p = ArchTest(e, lags = 10)$p.value,
             LjungBox_carres10_p = Box.test(e^2, lag = 10, type = "Ljung-Box")$p.value, row.names = NULL)
}

Causalité de Granger

\(X\) cause \(Y\) au sens de Granger si le passé de \(X\) améliore la prévision de \(Y\) une fois le passé de \(Y\) pris en compte. C’est une notion prédictive, pas une causalité physique, et elle ne concerne que les jours passés : le lien du jour même est mesuré par la causalité instantanée.

prevoir_var <- function(hist, h) {
  y <- hist[(nrow(hist) - P_VAR + 1):nrow(hist), , drop = FALSE]
  sortie <- matrix(NA, h, ncol(hist))
  for (s in 1:h) {
    z <- c(as.vector(t(y[P_VAR:1, , drop = FALSE])), 1)   # retards du plus récent au plus ancien, puis la constante
    sortie[s, ] <- as.vector(B %*% z)
    y <- rbind(y[-1, , drop = FALSE], sortie[s, ])
  }
  sortie
}

Cointégration

Deux séries I(1) sont cointégrées si une combinaison linéaire des deux est stationnaire : elles partagent alors un équilibre de long terme. Si c’est le cas, le bon modèle est un VECM ; sinon, c’est le VAR en différences estimé ci-dessus.

  • Phillips-Ouliaris (test sur les résidus, de la même famille qu’Engle-Granger). H0 : pas de cointégration.
  • Johansen (trace). On teste H0 : \(r = 0\), puis H0 : \(r \le 1\). On rejette quand la statistique dépasse la valeur critique à 5 %.
# Teste la cointégration sur les log-prix

3.3 Volatilité conditionnelle : GARCH

Le GARCH(1,1) modélise la variance du jour en fonction du choc de la veille (\(\alpha\), la réaction) et de la variance de la veille (\(\beta\), la mémoire) : \(\sigma_t^2 = \omega + \alpha\,\varepsilon_{t-1}^2 + \beta\,\sigma_{t-1}^2\). Il prévoit l’ampleur des variations, pas leur sens.
